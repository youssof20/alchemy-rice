# Alchemy 0.1.0a1

This is the first test-only Alchemy build. It is not a public beta.

Test it in a disposable KDE Plasma 6.6–6.8 user account or VM. Begin with `alchemy inspect`, review
the output, then follow the single color-scheme apply/revert sequence in the README. Do not test on
the only copy of a desktop configuration you care about.

Included in this build:

- read-only environment and supported-setting inspection;
- transactional plan, apply, verification, snapshot, revert, and recovery paths;
- declarative rice inspect/import/export and sanitized capture;
- semantic panel layouts;
- dependency resolution and reviewed package plans;
- gallery and pinned dotfile-repository import;
- Konsole, Kitty, Starship, and fastfetch visual adapters.

Known limits:

- real Plasma and distro integration results are still pending;
- Apply is disabled outside Plasma 6.6–6.8 or when capability checks fail;
- the downloadable wheel is not a native distro package;
- Fedora, Arch-family, Kubuntu, KDE neon, Debian, and openSUSE status must not be inferred from this
  prerelease alone.

The release includes `SHA256SUMS`. Verify it before installation when downloading artifacts
manually.
